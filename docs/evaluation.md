# FactGuard AI Evaluation & Metrics Documentation

## Academic Benchmark Metrics

The system tracks quantitative academic evaluation metrics:

- **Claim Extraction Accuracy**: Precision of atomic claim boundary identification.
- **Evidence Retrieval Precision**: Ratio of relevant retrieved snippets to total snippets.
- **Source Credibility Calibration**: Correlation between domain authority score (0-100) and expert review.
- **Verdict Accuracy**: Evaluation across pre-labeled true/false dataset.
- **Average Response Latency**: Time elapsed for full 7-agent graph execution (typically 1.2s - 2.5s).
- **Agent Failure Rate**: Multi-agent graph fallback safety score.
